# Danny.AI
Danny.AI is a Bubble-built interview practice prototype designed to explore how an AI-assisted platform could help users prepare for interviews through a structured, chatbot-style experience.

Project Overview

I created Danny.AI to practice building a functional web application from an idea into an interactive prototype. I designed the interface, navigation, interview flow, and overall user experience using Bubble.

The project helped me gain experience with no-code development, workflow design, debugging, and turning a concept into a usable product.

Features
Chatbot-style interview interface
Structured interview practice flow
Interactive navigation between application screens
Custom UI designed in Bubble
User-focused interview preparation concept
Built With
Bubble — application development and workflows
No-Code Development
UI/UX Design
Workflow Logic
Current Status

Danny.AI is currently a prototype. The interface, navigation, and interview workflow have been developed, while the chatbot functionality is still in development.

What I Learned

Through this project, I gained experience designing application workflows, troubleshooting functionality, developing user interfaces, and iterating on a product based on testing.
